# Portfolio Alfareza

Website portfolio pribadi yang dibuat untuk memperkenalkan diri, menampilkan latar belakang sebagai mahasiswa Informatika, serta menampilkan minat, keterampilan, dan beberapa proyek yang sedang dikembangkan serta sebagai memenuhi tugas submission web dasar.

## AI Usage & Dependency

Dalam pembuatan portfolio ini, saya menggunakan AI sebagai **alat bantu belajar, konsultasi, dan debugging**, terutama dalam memahami HTML semantic, CSS, Flexbox, responsive design, dan styling.

Saya tetap menentukan sendiri konsep, isi, struktur, serta desain portfolio dan melakukan penyesuaian kode berdasarkan hasil yang saya dapatkan.

### Tingkat Ketergantungan AI: Menurut saya sedang

AI cukup membantu dalam proses pengembangan, tetapi tidak sepenuhnya menggantikan proses pengerjaan saya. Beberapa kode dan konsep masih saya pelajari melalui proses bertanya, mencoba, dan memahami kembali cara kerjanya.

Saya menyadari bahwa penggunaan AI sebaiknya tidak hanya untuk menghasilkan kode, tetapi juga sebagai sarana untuk meningkatkan pemahaman dan kemampuan pemrograman saya.
