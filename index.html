Tentang Saya

Saya merupakan mahasiswa Informatika yang sedang membangun fondasi di bidang software development. Dalam proses belajar, saya telah mencoba berbagai bahasa pemrograman dan teknologi seperti Python, JavaScript, HTML, CSS, PHP, Java, Node.js, Django, React.js, dan MySQL.

Saya tertarik untuk memahami bagaimana sebuah aplikasi dibangun dari sisi frontend hingga backend, bagaimana data disimpan dan dikelola, serta bagaimana berbagai komponen tersebut dapat diintegrasikan menjadi sebuah sistem yang dapat digunakan.

Saya menyadari bahwa kemampuan saya masih terus berkembang. Karena itu, saya lebih memilih untuk terus belajar melalui praktik dan membangun project daripada hanya mempelajari teori. Setiap kesalahan dan bug yang saya temui menjadi bagian dari proses untuk memahami teknologi dengan lebih baik.

Proyek

Beberapa project berikut merupakan bagian dari proses saya dalam mempraktikkan ilmu yang saya pelajari dan mengeksplorasi bagaimana teknologi dapat digunakan untuk menyelesaikan masalah nyata.

  • KantinGo: Konsep sistem manajemen kantin digital dan Point of Sale (POS) yang bertujuan membantu proses pencatatan transaksi dan pelaporan penjualan secara lebih terstruktur.
  • NUGASin: Aplikasi manajemen tugas yang dirancang untuk membantu mahasiswa mengorganisir tugas, mengatur tenggat waktu, serta memantau progres pekerjaan dengan memanfaatkan database relasional.
  • ElectroHub: Aplikasi berbasis web untuk pengelolaan produk dan stok barang. Project ini menjadi salah satu media saya untuk mempelajari konsep CRUD, database, autentikasi, dan pengembangan backend menggunakan Node.js dan MySQL.
